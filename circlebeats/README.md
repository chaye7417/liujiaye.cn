# 交互式节奏圆环 - 用户使用指南

## 项目简介

交互式节奏圆环是一个基于Web的音乐创作平台，集成了AI图像生成、实时协作和智能聊天助手等功能。

![主界面](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/fengmiantu.png)

## 重要提示：左上角隐藏菜单

**特别注意**：主要控制菜单位于屏幕左上角，但默认是隐藏的！

![左上角菜单](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/zuoshangjiaocaidan.png)

**如何显示菜单**：
1. 将鼠标移动到屏幕的最左上角
2. 稍等片刻让菜单完全显示
3. 菜单会以绿色按钮的形式出现

**菜单功能**：
- **Hide Rhythm**：隐藏/显示节奏圆环界面
- **Show 3D Scene**：切换3D背景场景
- **Network Collaboration**：网络协作连接
- **Visualizer**：音乐可视化器控制
- **Overview**：总览视图切换

## 基础操作

### 1. 圆形步进器使用

![圆形步进器](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/zonglanxiaoyuanquan.png)

- **点击步进**：激活/停用音符
- **垂直拖拽**：调整音高
- **水平拖拽**：调整时值
- **空格键**：播放/暂停

### 2. 合成器控制

![合成器面板](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/hechengqi.png)

- **按S键**：打开合成器控制面板
- **波形选择**：正弦波、三角波、锯齿波、方波
- **ADSR包络**：控制音符的动态变化
- **效果器**：延迟、混响、滑音效果

## 网络协作

### 连接服务器

![协作连接](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/lianwangxiezuo_lianjiechenggong.png)

1. 点击左上角菜单的"Network Collaboration"
2. 等待连接成功
3. 查看在线用户数量

### 选择插槽

![插槽选择](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/lianwangxiezuo_xuanzechacao.png)

- 选择未被占用的插槽（无X标记）
- 每个插槽只能被一个用户控制
- 被占用的插槽会显示用户名

![占用状态](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/lianwangxiezuo_beizhanyongchacaodexianshi.png)

![总览模式](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/lianwangxiezuo_zonglanxiaoyuanquandemingzixianshi.png)

- 实时同步音乐模式
- 查看所有用户的创作内容
- 协同创建完整的音乐作品

## 快捷键

### 全局快捷键
- **空格键**：播放/暂停
- **V键**：切换音乐可视化器
- **H键**：隐藏/显示步进器界面
- **S键**：打开合成器控制面板
- **C键**：连接/断开协作服务器

### 编辑快捷键
- **数字键1-8**：快速切换插槽
- **Delete键**：清空当前插槽
- **Ctrl+C/V**：复制/粘贴模式

## 故障排除

### 常见问题
- **无声音**：检查浏览器音频权限和音量设置
- **找不到菜单**：确保鼠标悬浮在屏幕最左上角
- **连接失败**：检查网络连接状态
- **AI功能不可用**：检查网络连接

### 浏览器兼容性
推荐使用现代浏览器：
- Chrome 90+（推荐）
- Firefox 88+
- Safari 14+
- Edge 90+

## 快速开始流程

1. **打开应用**：在浏览器中访问应用
2. **显示菜单**：鼠标悬浮到左上角显示控制菜单
3. **选择插槽**：点击底部插槽按钮
4. **创建节奏**：在圆形界面中点击步进
5. **调整音色**：按S键打开合成器面板
6. **播放测试**：按空格键播放
7. **AI创作**：按V键启动可视化器，与小猫对话生成AI艺术
