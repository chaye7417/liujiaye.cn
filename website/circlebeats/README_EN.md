# Interactive Rhythm Ring - User Guide

## Project Overview

Interactive Rhythm Ring is a web-based music creation platform that integrates AI image generation, real-time collaboration, and intelligent chat assistant features.

![Main Interface](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/fengmiantu.png)

## Important Notice: Hidden Top-Left Menu

**Special Attention**: The main control menu is located in the top-left corner of the screen, but it's hidden by default!

![Top-Left Menu](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/zuoshangjiaocaidan.png)

**How to Display the Menu**:
1. Move your mouse to the very top-left corner of the screen
2. Wait a moment for the menu to fully appear
3. The menu will show up as green buttons

**Menu Functions**:
- **Hide Rhythm**: Hide/show rhythm ring interface
- **Show 3D Scene**: Toggle 3D background scene
- **Network Collaboration**: Network collaboration connection
- **Visualizer**: Music visualizer control
- **Overview**: Overview mode toggle

## Basic Operations

### 1. Circular Sequencer Usage

![Circular Sequencer](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/zonglanxiaoyuanquan.png)

- **Click Steps**: Activate/deactivate notes
- **Vertical Drag**: Adjust pitch
- **Horizontal Drag**: Adjust note duration
- **Spacebar**: Play/pause

### 2. Synthesizer Control

![Synthesizer Panel](../LaTeXTemplates_legrand-orange-book_v3-4/new_picture/hechengqi.png)

- **Press S Key**: Open synthesizer control panel
- **Waveform Selection**: Sine, triangle, sawtooth, square waves
- **ADSR Envelope**: Control note dynamics
- **Effects**: Delay, reverb, portamento effects

## Hotkeys

### Global Hotkeys
- **Spacebar**: Play/pause
- **V Key**: Toggle music visualizer
- **H Key**: Hide/show sequencer interface
- **S Key**: Open synthesizer control panel
- **C Key**: Connect/disconnect collaboration server

### Editing Hotkeys
- **Number Keys 1-8**: Quick slot switching
- **Delete Key**: Clear current slot
- **Ctrl+C/V**: Copy/paste patterns

## Troubleshooting

### Common Issues
- **No Sound**: Check browser audio permissions and volume settings
- **Can't Find Menu**: Ensure mouse hovers over the very top-left corner
- **Connection Failed**: Check network connection status
- **AI Features Unavailable**: Check network connection

### Browser Compatibility
Recommended modern browsers:
- Chrome 90+ (Recommended)
- Firefox 88+
- Safari 14+
- Edge 90+

## Quick Start Guide

1. **Open Application**: Access the application in your browser
2. **Display Menu**: Hover mouse over top-left corner to show control menu
3. **Select Slot**: Click slot buttons at the bottom
4. **Create Rhythm**: Click steps in the circular interface
5. **Adjust Timbre**: Press S key to open synthesizer panel
6. **Play Test**: Press spacebar to play
7. **AI Creation**: Press V key to start visualizer, chat with cat to generate AI art

Enjoy your musical creation journey!
